# An interactive quiz to learn Hangul, the Korean alphabet.

## About the project:
Hangul Game is a small interactive quiz designed to help beginners learn and practice the Korean alphabet through questions and challenges.

## Features
- Multiple-choice questions.
- Instant feedback for correct and incorrect answers.
- More features coming soon!

## Technologies
- HTML
- CSS (planned)
- JavaScript

## Future plans

- Point system.
- More questions.
- Consonants and vowels categories.
- Syllable formation.
- Korean vocabulary.
- Main lobby.
